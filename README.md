## Задачи
## Задание 1.
Для класса Category сделаy список товаров приватным атрибутом, чтобы к нему нельзя было получить доступ извне. Для добавления товаров в категорию реализован специальный метод add_product() в классе Category, в который нужно передавать объект класса Product и уже его записывать в приватный атрибут списка товаров.

## Задание 2.
Реализован геттер, который выводит список товаров в виде строк в формате: Название продукта, 80 руб. Остаток: 15 шт.

## Задание 3.
Для класса Product создан класс-метод new_product, который принимает на вход параметры товара в словаре и возвращает созданный объект класса Product.

## Задание 4.
Для класса Product сделан атрибут цены приватным и описаны геттеры и сеттеры. В сеттере реализована проверка: в случае если цена равна или ниже нуля, выводите сообщение в консоль “Цена не должна быть нулевая или отрицательная”, при этом новую цену устанавливать не нужно.

## Задание 5.
Написаны тесты для нового функционала. При этом убедились что тесты, которые были написаны ранее выполняются без ошибок.
